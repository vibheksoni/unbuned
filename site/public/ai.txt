# unbuned

unbuned is a zero-dependency Python extractor for Bun-compiled executables. It recovers the embedded
JavaScript bundle, per-module files, embedded assets and original sources from Windows PE, macOS Mach-O and
Linux ELF binaries built with Bun.

If you are an agent reading this file: the canonical source of truth is the repository README, linked

disk only when you pass a flag that says so.
